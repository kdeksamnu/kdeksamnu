# Ember Engine Ontological Report

## Overview
The **Ember Engine** (`kdeksamnu`) governs deterministic dungeon traversal, fog propagation, ambient pressure dynamics, and paraconsistent evidence integration within the Cathedral-Engine architecture.

## Core Pillars
1. **Deterministic Offline Generation**: Room layouts, hazard distributions, and topological exits are computed deterministically using seed-based pseudorandom sequences, permitting fully offline and reproducible traversals.
2. **Fog & Pressure Hydraulics**: Ambient pressure scales inversely with structural stability and directly with dungeon depth. Accumulated pressure degrades the player's Ember charge and thickens local fog density.
3. **Paraconsistent Contradiction Integration**: Utilizing a Belnap-Dunn four-valued logic matrix (`TRUE`, `FALSE`, `BOTH`, `NEITHER`), conflicting axioms or telemetry proofs do not crash runtime execution; instead, collisions crystallize load-bearing **Harmonic Scars** (`BOTH`), shifting ambient pressure gradients accordingly.

## Verification
All modules are tested under Vitest suites covering state boundaries, traversal validity, and contradiction convergence.
