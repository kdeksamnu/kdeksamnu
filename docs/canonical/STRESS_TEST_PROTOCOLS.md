# Stress Test Protocols I–X

**Chapter mapping is frozen:** XIX–XXVIII.

These protocols define tests; they do not constitute results.

## I — Dialetheic Defense / Locating the Transducer
**Chapter:** XIX
**Input:** simultaneous `A=true` and `A=false` for one atom.
**Primary observation:** runtime state becomes `BOTH` without logical explosion.
**Computational gate:** no exception; deterministic state record; persistent trace.
**Physical gate:** any physical transduction claim requires separately instrumented evidence.

## II — Dimensional Homogeneity Paradox
**Chapter:** XX
**Input:** explicit units for every term in the Architectonic Lagrangian.
**Primary observation:** additive terms have compatible dimensions.
**Failure:** dimensional mismatch or undefined unit conversion.

## III — Ontological Status of the Belnap-Dunn Matrix
**Chapter:** XXI
**Input:** exhaustive `T/F/B/N` lattice operations.
**Primary observation:** operations remain within the defined lattice and preserve ordering rules.
**Failure:** invalid state or explosion into arbitrary propositions.

## IV — Thermodynamic Limit of Immutability
**Chapter:** XXII
**Input:** archive append, verification, migration, restoration.
**Primary observation:** cryptographic lineage remains recoverable after migration.
**Physical energy claims:** require actual instrumentation and must not be inferred from the software trace alone.

## V — Algorithmic Time Complexity
**Chapter:** XXIII
**Input:** controlled contradiction-insertion workload.
**Primary observation:** fixed-buffer insertion path follows the specified bounded operation without dynamic allocation.
**Failure:** allocation, unbounded path growth, or buffer overrun.

## VI — Sovereign Spark Protocol
**Chapter:** XXIV
**Input:** fixed initialization state, seed, and archive root.
**Primary observation:** deterministic verified initialization.
**Failure:** divergent initialization or failed verification.

## VII — Falsifiability of Somatic Rendering
**Chapter:** XXV
**Input:** valid and invalid telemetry payloads.
**Primary observation:** render transitions follow the defined telemetry-validation boundary.
**Failure:** ungrounded runtime transition under the test's specified conditions.

## VIII — Authority of the Decalogue
**Chapter:** XXVI
**Input:** deliberate attempts to violate each defined runtime invariant.
**Primary observation:** violations are detected, blocked, and archived according to the implementation specification.
**Failure:** unauthorized transition commits.

## IX — Causal Efficacy of the 40-Book Codex
**Chapter:** XXVII
**Input:** fixed Codex source and compiler environment.
**Primary observation:** deterministic implementation artifacts with explicit semantic/computational/physical separation.
**Failure:** nondeterministic compilation or unsupported direct-physical-causation inference.

## X — Simulation / Reality Boundary
**Chapter:** XXVIII
**Input:** traced specification-to-runtime execution.
**Primary observation:** semantic specification, computational execution, and physical observation remain distinct layers.
**Failure:** an unsupported direct-force claim replaces the documented implementation path.

## Experimental rule

Every executed test must record:

1. test version;
2. source/specification hash;
3. environment;
4. inputs;
5. procedure;
6. expected result;
7. actual result;
8. anomalies;
9. run identifier;
10. archive hash;
11. reproduction status.

No protocol becomes `EMPIRICAL` merely because its expected result is written here.
